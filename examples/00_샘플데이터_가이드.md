## 01. 아이스크림 가게 — 프론티어를 눈으로 보기

**상황** — 여름 성수기 동네 아이스크림 가게 10곳의 하루 영업 자료입니다. 알바 몇 명을 써서 하루에 몇 컵을 파는가, 그것뿐입니다.

**설정**

| 항목 | 값 |
|---|---|
| DMU name | 가게명 |
| Inputs | 알바수 |
| Outputs | 일판매컵수 |
| Model / Orientation | BCC / input |

**결과**

효율적인 가게 **5곳**, 평균 효율성 **0.88**, 최저 **0.62**(북극곰냉장고)
규모수익 — IRS 4곳, CRS 1곳, DRS 5곳

| 가게 | 알바수 | 판매컵수 | 효율성 | RTS |
|---|---|---|---|---|
| 달콤한하루 | 2.0 | 120 | 1.000 | IRS |
| 구름아이스 | 3.5 | 250 | 1.000 | IRS |
| **펭귄스쿱** | 5.0 | 364 | 1.000 | **CRS** |
| 바닐라정거장 | 7.0 | 503 | 1.000 | DRS |
| 설탕공장 | 9.5 | 665 | 1.000 | DRS |
| 민트초코대첩 | 3.3 | 175 | 0.798 | IRS |
| 여름방학 | 4.8 | 304 | 0.877 | IRS |
| 쌍쌍바네 | 8.6 | 435 | 0.700 | DRS |

| 북극곰냉장고 | 14.5 | 633 | 0.621 | DRS |

**읽는 법**

- **북극곰냉장고**는 알바 14.5명으로 633컵을 팝니다. 그런데 설탕공장은 9.5명으로 665컵을 파니, 더 적은 인력으로 더 많이 파는 셈입니다. 효율성 0.62는 "같은 판매량을 62% 인력으로도 가능하다"는 뜻입니다.

**꼭 해보실 것** — `7. Visualization` → `A. Figures` → **DEA - Efficiency frontier & DMU positions**

투입과 산출이 하나씩이라 **프론티어가 정확한 모양 그대로** 그려집니다. 효율적인 5개 가게를 잇는 오목한 꺾은선이 프론티어이고, 비효율 매장에서 왼쪽으로 뻗은 주황색 선이 "여기까지 인력을 줄일 수 있다"는 투영선입니다. DEA를 설명할 때 이 그림 하나면 충분합니다.

## 02. 카페 — 규모수익 이해하기

**상황** — 서울 도심 카페 24곳. 바리스타와 매장 면적을 투입해 매출을 만듭니다. 작은 테이크아웃 매장부터 대형 로스터리까지 규모가 다양합니다.

**설정**

| 항목 | 값 |
|---|---|
| DMU name | 카페명 |
| Inputs | 바리스타수, 매장평수 |
| Outputs | 월매출_만원 |
| Model / Orientation | BCC / input |

**결과**

효율적인 카페 **6곳**, 평균 **0.87**, 최저 **0.68**(커피정원)
규모수익 — **IRS 11곳, CRS 2곳, DRS 11곳**

**읽는 법**

- **라떼공작소**(4명·32평)와 **원두수도원**(5.5명·64평)이 CRS로, 이 상권의 최적 규모입니다.
- **커피정원**은 바리스타 9.4명에 82평인데 월매출은 2,651만원입니다. 비슷한 규모의 카페시나몬(8명·77평)이 3,479만원을 올리니 명백한 열위입니다.
- **`Peers` 열**을 보십시오. 비효율 카페마다 "누구를 벤치마킹해야 하는지"가 가중치와 함께 나옵니다. 컨설팅 보고서에 바로 쓸 수 있는 정보입니다.

**더 해볼 것**

`Model`을 **CCR**로 바꿔 다시 실행해 보십시오. 점수가 전반적으로 낮아집니다. **CCR ÷ BCC = 규모효율성**이며, 이 값이 1보다 작다는 것은 "운영은 잘하는데 규모가 안 맞는다"는 뜻입니다.

## 03. 수제버거 — 부트스트랩이 필요한 이유

**상황** — 수제버거 전문점 18곳. 일반 DEA를 돌리면 **8곳이 나란히 1.0**을 받습니다. 그런데 정말 이 8곳이 똑같이 잘하는 걸까요?

**설정**

| 항목 | 값 |
|---|---|
| DMU name | 매장명 |
| Inputs | 주방인력, 좌석수 |
| Outputs | 월판매수량 |
| Model / Orientation | BCC / input |
| B | 1000 (논문용은 2000 권장) |
| alpha | 0.05 |

**결과** — 동점이 풀립니다

| 매장 | 원점수 | 편의보정(Mean) | CI 하한 | CI 상한 |
|---|---|---|---|---|
| 수제의품격 | 1.000 | **0.957** | 0.917 | 0.988 |
| 베이컨연구소 | 1.000 | 0.956 | 0.897 | 0.990 |
| 치즈폭포 | 1.000 | 0.949 | 0.894 | 0.989 |
| 그릴마스터 | 1.000 | 0.937 | 0.872 | 0.989 |
| 심야버거 | 1.000 | 0.907 | 0.736 | 0.988 |
| 번즈앤번즈 | 1.000 | 0.905 | 0.769 | 0.989 |
| 불꽃패티 | 1.000 | **0.879** | **0.640** | 0.990 |
| 왕관버거 | 1.000 | **0.873** | **0.628** | 0.989 |

**읽는 법 — 이 표가 핵심입니다**

1. **동점이 사라집니다.** 1위는 수제의품격(0.957), 8위는 왕관버거(0.873)로 갈립니다.
2. **신뢰구간 폭이 신뢰도를 말해줍니다.** 수제의품격은 0.917~0.988로 좁아 "확실히 잘한다"고 말할 수 있습니다. 반면 불꽃패티는 0.640~0.990으로 폭이 넓어 **1.0이라는 점수를 그대로 믿기 어렵습니다.**
3. **순위가 뒤집힙니다.** 원래 1.0이던 불꽃패티(보정 후 9위)와 왕관버거(10위)는, 원점수 0.94였던 양파링장인(0.890)보다 **낮은 순위로 밀려납니다.**

효율적 DMU가 많을수록 DEA의 순위 정보는 빈약해집니다. 부트스트랩은 그 한계를 통계적으로 보완합니다. 논문에서 효율성 점수를 회귀분석에 쓸 때 원점수 대신 **편의보정 점수(Mean)**를 권하는 이유이기도 합니다.

**참고** — 부트스트랩은 난수를 쓰므로 실행할 때마다 소수점 아래 값이 조금씩 달라집니다. 순위의 큰 그림은 유지됩니다.

## 04. 치킨집 — 배달앱이 바꾼 생산성

**상황** — 치킨 프랜차이즈 20개 매장의 2021~2025년 자료입니다.

> 2022년 배달앱이 본격 도입되며 업계 전체의 생산 기술이 한 단계 올라섰습니다. 그런데 2023년, 배달 수수료 부담이 커지며 오히려 뒷걸음질쳤습니다. 이후 2024~2025년에 다시 회복합니다.

**설정**

| 항목 | 값 |
|---|---|
| DMU name | 매장명 |
| **Period variable** | **연도** (반드시 지정) |
| Inputs | 직원수, 매장평수 |
| Outputs | 월매출_만원 |
| Model / Orient | BCC / input |

**결과**

| 구간 | EC | TC | MI | 생산성 하락 매장 |
|---|---|---|---|---|
| 2022 | 1.007 | **1.174** | **1.183** | 0 / 20 |
| 2023 | 0.988 | **0.933** | **0.921** | **16 / 20** |
| 2024 | 0.987 | 1.126 | 1.112 | 1 / 20 |
| 2025 | 0.968 | 1.166 | 1.129 | 0 / 20 |
| **전체** | **0.987** | **1.095** | **1.081** | |

**읽는 법**

- **2022년 TC = 1.174** — 프론티어 자체가 17% 바깥으로 이동했습니다. 배달앱이라는 기술 도입 효과입니다.
- **2023년 TC = 0.933** — 프론티어가 후퇴했습니다. 수수료 부담으로 같은 투입으로 낼 수 있는 최대 산출이 줄어든 것입니다. 이 해에는 **20곳 중 16곳의 생산성이 하락**했습니다.
- **EC는 전 기간 0.99 안팎** — 매장들이 프론티어를 따라잡지 못했다는 뜻입니다. 즉 **이 업계의 생산성 향상은 개별 매장의 노력(EC)이 아니라 업계 전체의 기술 변화(TC)가 이끌었습니다.**
- 소규모 매장일수록 2022년 TC가 높습니다. 배달앱의 수혜가 작은 매장에 더 컸다는 설정입니다.

**꼭 해보실 것** — `7. Visualization` → **Malmquist - EC vs TC quadrant**, `Period`를 **2023**으로

가로축 EC(따라잡기), 세로축 TC(기술변화)의 사분면에 매장들이 흩어집니다. 대부분이 아래쪽(TC<1)에 몰리되 EC는 좌우로 퍼져, "**업황은 나빴지만 그 안에서도 따라잡은 매장과 뒤처진 매장이 갈렸다**"는 그림이 나옵니다.

**Malmquist - MI / EC / TC trend by period**도 함께 보십시오. 2023년에 TC 선만 아래로 꺾이는 모습이 한눈에 들어옵니다.

## 05. 헬스장 — 무엇이 효율성을 만드는가

**상황** — 동네 헬스장 45곳. 효율성 차이가 **입지 조건**에서 오는지 검정합니다. 환경변수 3개는 헬스장이 스스로 바꾸기 어려운 조건들입니다.

**설정**

| 항목 | 값 |
|---|---|
| DMU name | 헬스장명 |
| Inputs | 트레이너수, 시설면적_평 |
| Outputs | 월회원수 |
| **Environmental vars** | **역세권거리_m, 경쟁헬스장수, 개업연차** |
| Model / Orientation | BCC / input |
| Dependent / Method | Raw efficiency (DEA) / **Tobit** |

> `5. 2nd-stage Regression`을 실행하려면 **`2. DEA`를 먼저** 돌려야 합니다.

**결과**

DEA — 45곳 중 **15곳이 효율적**, 평균 0.889

Tobit 회귀 (n=45, 수렴 성공)

| 변수 | 계수 | 표준오차 | z | p |
|---|---|---|---|---|
| 상수항 | 1.0447 | 0.0444 | 23.52 | <0.001 *** |
| **역세권거리_m** | **−0.000192** | 0.000032 | −6.03 | <0.001 *** |
| **경쟁헬스장수** | **−0.0322** | 0.0054 | −5.93 | <0.001 *** |
| **개업연차** | **+0.0160** | 0.0034 | +4.76 | <0.001 *** |

Wald 통계량 87.48 (p<0.001)

**읽는 법**

- **역세권거리** 계수 −0.000192 — 역에서 **100m 멀어질 때마다 효율성이 약 0.019 하락**합니다. 500m면 0.096, 즉 10% 가까운 손실입니다.
- **경쟁헬스장수** 계수 −0.032 — 반경 1km에 **경쟁점이 하나 늘 때마다 효율성 0.032 하락**.
- **개업연차** 계수 +0.016 — **1년 오래 운영할수록 0.016 상승**. 단골 확보와 운영 노하우의 효과로 해석할 수 있습니다.

계수의 절대 크기가 아니라 **변수의 단위를 곱한 값**으로 해석해야 한다는 점이 중요합니다. 역세권거리 계수는 작아 보이지만 단위가 미터라서 그렇습니다.

**더 해볼 것**

`Method`를 **Truncated**, **OLS**로 바꿔 각각 실행한 뒤 `7. Visualization` → `B. Publication tables` → **Second-stage regression - all stored models**를 만들어 보십시오. **세 모형이 한 표에 나란히** 배치되어 논문에 그대로 넣을 수 있습니다.

## 06. 편의점 — 집단 간 차이 검정

**상황** — 편의점 60곳. 집단 변수가 두 개 들어 있어 **2집단 비교와 3집단 비교를 모두** 연습할 수 있습니다.

- **영업형태** — 24시간(1) vs 단축영업(0)
- **상권유형** — 오피스 / 대학가 / 주거지

**설정**

| 항목 | 값 |
|---|---|
| DMU name | 점포명 |
| Inputs | 근무자수, 매장평수 |
| Outputs | 일평균방문객 |
| **Group variable** | **영업형태** 또는 **상권유형** (바꿔가며 실행) |
| Model / Orientation | BCC / input |

### (1) 영업형태 — 2집단, 모수 검정

`Group variable`을 **영업형태**로 두고, `6. Group Tests`에서 **Bias-corrected efficiency (Bootstrap)**를 선택하면 t검정이 적용됩니다.

```
Levene 등분산 검정:  p = 0.716  →  등분산 가정 충족
Student t-test:      t = 4.93,  p < 0.001 ***

24시간 운영 (n=32):  평균 0.911
단축 영업  (n=28):  평균 0.806
```

**읽는 법** — Levene 검정 p가 0.05 이상이므로 등분산을 가정한 **Student t검정**이 채택됩니다. PLEAP은 Welch 결과도 함께 보여주고 마지막 줄에 `-> reported`로 실제 채택된 값을 표시합니다. **SPSS 출력과 그대로 대조**할 수 있습니다.

24시간 운영 점포가 유의하게 더 효율적입니다.

### (2) 상권유형 — 3집단, 비모수 검정

`Group variable`을 **상권유형**으로 바꾸고 **Raw efficiency (DEA)**를 선택하면 Kruskal-Wallis가 적용됩니다.

```
Kruskal-Wallis:  H = 15.74,  p < 0.001 ***

중앙값:  오피스 0.936  >  대학가 0.891  >  주거지 0.801

Dunn 사후검정 (Bonferroni 보정)
  주거지 < 오피스   p = 0.0003  ***
  주거지 < 대학가   p = 0.0227  **
  대학가 vs 오피스  p = 0.6854  n.s.
```

**읽는 법 — 여기가 중요합니다**

전체 검정은 p<0.001로 유의하지만, **모든 쌍이 유의한 것은 아닙니다.** 대학가와 오피스 사이에는 통계적으로 의미 있는 차이가 없습니다. 차이를 만드는 것은 **주거지 상권의 낮은 효율성**입니다.

전체 검정만 보고 "세 상권이 모두 다르다"고 결론 내리면 잘못입니다. **사후검정을 반드시 확인**해야 한다는 점을 보여주는 사례입니다.

## 데이터에 대한 안내

모든 데이터는 **교육용으로 만든 가상 자료**입니다. 실제 업체나 통계와는 관련이 없습니다.

`sample_data.xlsx`는 PLEAP 논문(SoftwareX) 3절의 예제입니다. 60개 DMU × 3기간(2021–2023), 투입 2개(x1, x2), 산출 2개(y1, y2), 환경변수 2개(z1, z2), 집단 3개(A/B/C)로 구성된 **가상 패널**이며, `tests/data/make_synthetic_data.py`가 정해진 생성 과정과 고정된 시드로 만듭니다. v1.11까지 쓰던 같은 이름의 예제는 실제 자료에서 나온 것이어서 v1.12부터 이 가상 자료로 바꾸었습니다.

효율적 프론티어를 먼저 설계한 뒤 각 매장을 의도한 만큼 안쪽으로 배치하는 방식으로 만들었기 때문에, 결과가 우연이 아니라 **설명 가능한 형태로 나옵니다.** 다만 실제 데이터는 이보다 훨씬 지저분하며, 결과가 이렇게 깔끔하게 갈리지 않는 것이 정상입니다.
